SECTION 0: EXTERIOR CASING & MYSTERY CHAMBER

Before attempting to disarm any module, cross-reference the four casing features below. Some features are only visible to the Deaf observer; others can only be felt by the Blind technician.

CASING FEATURE INSPECTION SPECIFICATION
SERIAL NUMBER A 6-character alphanumeric code on the casing exterior.
• Check whether it contains a VOWEL (A, E, I, O, U).
• Check whether the FINAL DIGIT is ODD (1, 3, 5, 7, 9) or EVEN (0, 2, 4, 6, 8).
BATTERY MOUNT Count the total number of AA battery cells mounted to the side of the chassis (0, 1, or 2 Batteries).
INDICATOR TAG Inspect the status label affixed to the chassis: either LIT: FRK or UNLIT: CAR.
MYSTERY CHAMBER A curtained side access port containing one concealed object:
• METAL KEY (flat, notched teeth)
• AA BATTERY (smooth cylinder, raised terminal nub)
• SPIKY BALL (round, prickly rubber nubs)
• WOOD BLOCK (smooth flat faces, sharp corners)
• PADLOCK (heavy metal body with curved shackle loop)

DISARMING REQUIREMENTS & STRIKE PENALTIES

The bomb is armed with a 5:00 MINUTE timer and three active modules: Module 1 (Tactile Wires), Module 2 (Shape Dials), and Module 3 (Toggle Switches).

Modules may be disarmed in any sequence, provided all cross-referenced dependencies are satisfied. Any incorrect wire disconnection, dial alignment, switch state, or communication violation triggers a STRIKE and accelerates the timer. Three Strikes result in immediate detonation.

MODULE 1: ON THE SUBJECT OF TACTILE WIRES

Five horizontal colored wires are clipped across the chassis from Slot 1 (Top) to Slot 5 (Bottom). Each wire slot is paired with a tactile texture badge on the left edge. Note that texture badges may be shuffled between slots on different bombs.

ONLY ONE WIRE MAY BE DISCONNECTED.
EVALUATE CONDITIONS 1 THROUGH 6 IN STRICT TOP-TO-BOTTOM ORDER.
EXECUTE ONLY THE FIRST CONDITION THAT IS TRUE!

WIRE DISCONNECTION TABLE

PRIORITY CONDITION DISCONNECT TARGET
CONDITION 1 If the Mystery Chamber contains a PADLOCK AND there is NO Black wire on the bomb: Disconnect the wire beside the METAL COIN badge.
CONDITION 2 Otherwise, if the Serial Number contains a VOWEL AND a RED wire is present anywhere on the bomb: Disconnect the wire beside the SANDPAPER badge.
CONDITION 3 Otherwise, if there are 2 BATTERIES on the casing AND a YELLOW wire is present anywhere on the bomb: Disconnect the wire beside the SOFT FELT badge.
CONDITION 4 Otherwise, if a WHITE wire is mounted in an ODD slot (Slot 1, Slot 3, or Slot 5): Disconnect the wire beside the BUBBLE WRAP badge.
CONDITION 5 Otherwise, if the Mystery Chamber contains a METAL KEY: Disconnect the wire beside the RIBBED CARD badge.
CONDITION 6 Otherwise, if none of Conditions 1–5 apply: Disconnect the wire in SLOT 3 (Middle Slot), regardless of its texture badge.

MODULE 2 // DIALS
SECTION: 02-DIA
ROTATING SHAPE DIALS

MODULE 2: ON THE SUBJECT OF SHAPE DIALS

Three rotary dials are mounted on the upper casing, each marked with a raised 3D geometric shape: Triangle (▲), Square (■), and Circle (●). Each dial must be rotated to one of four cardinal directions: UP, DOWN, LEFT, or RIGHT.

▲ UP ◄ LEFT ( DIAL ROTOR ) RIGHT ► ▼ DOWN [ ▲ TRIANGLE ] [ ■ SQUARE ] [ ● CIRCLE ] (Dial 1) (Dial 2) (Dial 3)

Align Dial 1 (Triangle) and Dial 2 (Square) first, as Dial 3 (Circle) depends on their final alignments.

DIAL 1: TRIANGLE ROTOR (▲)

EVALUATE TOP-TO-BOTTOM (FIRST TRUE CONDITION): TARGET DIRECTION
1. If the Mystery Chamber contains a SPIKY BALL: Rotate UP (▲)
2. Else, if the Indicator Tag displays LIT: FRK: Rotate RIGHT (►)
3. Else, if the Serial Number ends in an ODD DIGIT (1, 3, 5, 7, 9): Rotate LEFT (◄)
4. Otherwise: Rotate DOWN (▼)

DIAL 2: SQUARE ROTOR (■)

EVALUATE TOP-TO-BOTTOM (FIRST TRUE CONDITION): TARGET DIRECTION
1. If there is at least 1 BATTERY (1 or 2 Batteries) on the casing: Rotate UP (▲)
2. Else, if the Mystery Chamber contains a WOOD BLOCK: Rotate LEFT (◄)
3. Otherwise: Rotate RIGHT (►)

DIAL 3: CIRCLE ROTOR (●)

EVALUATE BASED ON DIAL 1 & DIAL 2 FINAL POSITIONS: TARGET DIRECTION
1. If the TRIANGLE DIAL is set to UP (▲): Rotate UP (▲)
2. Else, if the SQUARE DIAL is set to UP (▲): Rotate LEFT (◄)
3. Otherwise (neither Triangle nor Square points UP): Rotate DOWN (▼)

TOGGLE SWITCH MATRIX

MODULE 3: ON THE SUBJECT OF TOGGLE SWITCHES

Four vertical toggle switches are arranged in a horizontal bank, numbered Switch 1, Switch 2, Switch 3, and Switch 4 from left to right. All four switches must be set to their correct final polarity (UP or DOWN).

SWITCH POLARITY RULES (EVALUATE ALL FOUR SWITCHES)

SWITCH SET TO "UP (▲)" IF... SET TO "DOWN (▼)" IF...
SWITCH 1 The Serial Number contains at least one VOWEL (A, E, I, O, U). The Serial Number contains no vowels.
SWITCH 2 The Mystery Chamber contains a METAL KEY or an AA BATTERY. The Mystery Chamber contains a Spiky Ball, Wood Block, or Padlock.
SWITCH 3 There are 0 BATTERIES on the casing OR the Indicator Tag reads UNLIT: CAR. There is 1 or 2 Batteries AND the Indicator Tag reads LIT: FRK.
SWITCH 4 SWITCH 1 is in the UP (▲) position. SWITCH 1 is in the DOWN (▼) position.
